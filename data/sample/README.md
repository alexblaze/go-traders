# Sample data — DEMO DATA

Everything in this folder is **synthetic** and generated by `scripts/generate-demo-data.ts`
(deterministic GBM with a shared market factor, regime shifts and volume spikes).

* Symbols are fictional (`DM…`) and company names end in "(DEMO DATA)".
* Prices are **not** authentic NEPSE history and must never be presented as such.
* `import-example.csv` shows the CSV import format:

```
symbol,date,open,high,low,close,volume,turnover
NABIL,2026-01-01,500,510,495,505,120000,60600000
```

To analyse real data, import your own NEPSE CSV via the Admin → Data Import page
(or `POST /api/v1/admin/imports`); the data source label then switches to `IMPORTED`.
